# FootballAI Assistant – CRUD „Клубове“

## Описание

Това е Python модул за управление на футболни клубове с **SQLite база данни**.  
Проектът е част от **Етап 2** на годишния проект за 11 клас – Python + SQL връзка + CRUD за таблица `clubs`.

Основни функции:
- Създаване на връзка към база данни чрез `db.py`
- Създаване, четене, обновяване и изтриване на записи в таблица `clubs` (CRUD)
- Защита срещу SQL injection чрез параметризирани заявки
- Минимален тестов сценарий (`main.py`) за проверка на функционалността

Базата данни се създава автоматично от `schema.sql` при първо стартиране.
